# ACP 会话与连续输入

状态：已实现并通过本地验证；真实飞书与模型待部署验收。基于 ACP v1、claude-agent-acp 0.106.0 和 SDK 2.6.0；v2 仍为实验协议，当前不迁移。

## 约定

- 会话绑定属于账号、聊天、话题、用户和工作区。任务结束不清空上下文；四小时期限只回收运行资源。`/new` 显式换上下文，`/resume` 选择本人历史。
- 恢复优先使用协商的 `session/resume`，其次 `session/load`。恢复失败不调用 `session/new` 执行原输入；保留绑定和失败任务原文，用户可重试或明确 `/new`。
- 同一任务内的连续 prompt 使用当前运行时。跨任务先关闭进程，下次恢复同一会话；释放时优先协商的 `session/close`，有界等待后终止进程。ACP v1 的 prompt 结束不能证明后台活动已停止，暂不跨任务热复用，避免迟到输出归属错误和脱离任务时限的执行。四小时配置保留为空闲资源清理兜底，实际任务结束即回收。
- 每个活动任务持有有界输入缓冲；准备期间及连续补充按到达顺序保留。缓冲不是独立任务队列，不跨任务或用户注入。`/queue` 仍创建独立工作项。
- 执行中普通输入通过原生 steering。`injected` 表示适配器确认投递；`promptRequired` 明确未投递，由 Bridge 在当前任务内、同一会话发起下一轮。超时和断线不重发。
- 原生 slash 命令经过普通 prompt 路径，不用 steering 冒充命令执行。Bridge 查询、取消和回答命令立即处理。
- 图片及文本附件使用相同内容块转换、能力校验和下载限制；异步下载后再次确认任务归属及取消状态。
- 表单保留选择加备注、逐项答案、修改和部分跳过。多项表单提交前展示摘要，单项直接文字回答保持简洁；显式 JSON 为一次完整提交。普通提问仍由同一会话的下一轮回答。
- ACP v1 通过适配器的 `backgroundSubagents` 扩展先返回主回复。Bridge 仅订阅限定的 Claude SDK 生命周期事件，等待已跟踪的后台活动结束和 Claude 报告会话空闲，并在同一任务内接收后续汇总和提问。`session/status` 的 open/saved 仅用于描述会话的恢复状态。后台活动的时限、取消和工作区归属继承原任务。

## 验证

使用可控 stdio fixture 检查恢复、同任务连续 prompt、跨任务进程隔离、关闭及失败行为；Bridge 测试覆盖启动补充、连续补充、轮次结束竞争、取消、附件、命令和跨用户隔离。表单测试覆盖选项加说明、多项修改和部分提交。全量类型检查、测试、构建及打包 smoke 通过后仍需真实飞书与模型验收。
