# 对话输入与显式队列

普通消息先按所属会话的提问关联处理；没有待答请求时，执行中的文字或附件默认引导当前会话。准备期间及连续补充保存在当前任务最多 20 条的输入缓冲中，按序投递。独立任务通过 /queue <内容> 创建；缓冲和独立队列都不跨用户、账号、聊天或话题。

提问支持精确选项、编号、自定义答案、选择加备注、逐字段填写、修改及部分跳过。多字段最终核对后提交，单字段及完整 JSON 直接提交。飞书父消息关联覆盖原问题和后续草稿；仅已识别的本人问题允许群聊无 @ 回答，仍取决于飞书事件权限及父消息字段。保留最近 1024 条内存关联以拒绝过期答案；重启和淘汰后的旧回复无法可靠识别。

steering 依赖能力协商，injected 确认投递；promptRequired 明确未投递，自动在同一任务、同一会话继续 prompt。未知结果不重试。原生 slash 命令通过 prompt 路径在轮次边界执行；控制命令立即处理。附件沿用已有体积、类型及 image 能力校验，取消后不再投递。

闲置清理保留上下文。恢复优先协商的 resume，其次 load；恢复失败停止执行，不能静默新建。同一任务内连续 prompt 复用运行时；跨任务关闭进程再恢复会话，避免 ACP v1 未跟踪的后台活动跨任务串扰，四小时清理保留为兜底。/new 明确新开。输入缓冲不持久化，重启不重放；后台任务及子代理控制未开放。

验证包含 stdio fixture、启动与连续输入、轮次衔接、附件取消、跨用户隔离、重复消息、表单修改、精确回复和过期答案。真实飞书及模型行为仍需部署验收。
